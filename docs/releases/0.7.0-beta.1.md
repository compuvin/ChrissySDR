# ChrissySDR 0.7.0-beta.1

This is a beta test release for licensed amateur-radio operators using SoapyRemote on a LAN. It is not a production-ready transmitter.

Since v0.5.3:

- Completed the 0.6 receiver acceptance gate by operator sign-off, including
  the FLEX-1500 and a second radio at a substantially different sample rate.
- Added microphone-originated AM, NFM, USB, and LSB transmit pipelines with tap-to-latch PTT and a configurable timeout.
- Reused one SoapyRemote device connection across RX and TX handoffs, reducing key-up delay and avoiding repeated device opens.
- Fixed returning to the active radio from the notification and restored consistent spectrum smoothing afterward.
- Moved Settings to a top-opening panel and refined its scrolling and layout.
- Added per-mode receive squelch and optional Light/Strong spectral noise reduction. RNNoise and DeepFilterNet were evaluated and removed after on-device testing.

Known limits and cautions:

- Transmit is still under development. TX capability configuration, fault-triggered immediate unkeying, and controlled validation of every mode remain on the roadmap.
- Transmit only where you are licensed and use a dummy load or controlled endpoint for testing.
- This APK is debug-signed for testing, not production-signed or a Google Play build.
- If upgrading from a dev.19 or dev.20 test APK, clear ChrissySDR app storage first. That removes saved radio profiles; the temporary DeepFilterNet database schema is not carried forward.
