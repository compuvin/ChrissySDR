# ChrissySDR 0.5.3 — bug-fix release

This is a bug-fix release. No new features were added.

- Fixed RX frequency and compatible mode/filter changes unnecessarily closing
  and reopening the SoapyRemote stream.
- Fixed the active-radio notification opening a second screen that incorrectly
  showed RX as stopped while audio continued.
- Fixed the spectrum snapping back briefly after a drag.
- Fixed spectrum span and zoom rendering on radios with sample rates above
  48 kHz, including finer FFT detail when zoomed in.

The attached APK is debug-signed for testing. It is not a production-signed or
Google Play build. Transmit remains an early controlled test facility, not a
production-ready transmitter.
