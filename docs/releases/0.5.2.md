# ChrissySDR 0.5.2

This release contains a debug-signed Android APK for testing. It is not a
production-signed or Google Play build.

Highlights since 0.5.1:

- Live spectrum display with tap/drag tuning and continuous pinch zoom. Spectrum
  span presets remain in Settings.
- Separate Operating Controls and Settings, plus one-tap Quick Connect for saved
  radio profiles.
- In-app diagnostics with Copy and Share, and capability-aware RX controls.
- NFM receive DSP and audio filtering; live NFM reception still needs testing.
- Foreground RX notification with working Stop audio and Pause/Resume audio
  actions.

Transmission remains an early controlled test facility, not a production-ready
transmitter. Use only with a licensed operator and appropriate test setup.
Background audio, audio-route interruptions, and NFM reception still need
broader device testing.
